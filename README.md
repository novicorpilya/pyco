# PYCO: Инновационная EdTech Платформа

![PYCO Logo](/public/favicon.png)

**PYCO** — это высокопроизводительный игровой движок на базе веб-технологий, спроектированный для геймификации обучения Python. Это не просто игра, а масштабируемая архитектурная база (MVP v1.0), созданная для проверки гипотез вовлеченности в EdTech-секторе.

---

## 🏗 Архитектурная философия (Senior Approach)

В отличие от стандартных монолитных игровых решений, PYCO построен на принципах ** Separation of Concerns** (разделения ответственности):

*   **Hybrid Rendering Engine**: Использование **Phaser.js 3** исключительно для игрового цикла (Core Loop) и **React 19** для управления состоянием интерфейса и порталов. Это позволяет интегрировать веб-интерфейсы любой сложности без нагрузки на игровой поток.
*   **Feature-Sliced Design (FSD)**: Архитектура проекта подготовлена к агрессивному масштабированию. Все сущности (Entities), фичи и виджеты изолированы, что минимизирует технический долг при добавлении новых уровней.
*   **Type-Safe Communication**: Взаимодействие между Phaser и React реализовано через строго типизированную шину событий (**EventBus**), исключающую ошибки рассинхронизации состояний.

## 🛠 Технологический стек и стратегический выбор

| Технология | Назначение | Обоснование |
| :--- | :--- | :--- |
| **React + Vite** | UI Layer | Максимальная скорость HMR и интеграция с современными веб-экосистемами. |
| **Phaser.js 3** | Game Core | Промышленный стандарт для HTML5-игр с открытым кодом. |
| **Zustand** | State Management | Легковесный и производительный менеджер состояний для синхронизации мета-данных игры (XP, HP). |
| **Vercel Serverless** | Feedback API | Реализация Zero-Infrastructure бэкенда для мгновенной обратной связи. |
| **Telegram Bot API** | Tracking & Feedback | Использование Lean-методологии для сбора пользовательских данных без создания громоздких админ-панелей. |

## 📈 Roadmap развития (Scale-Up Strategy)

Проект спроектирован с учетом перехода на Senior-уровень реализации:
*   **Q2 2026: Интеграция Pyodide (WASM)**. Исполнение реального Python-кода ученика напрямую в браузере с использованием изолированных Web Workers.
*   **Q2 2026: Data-Driven Levels**. Переход на загрузку уровней из JSON (Tiled Maps), полностью отделяя контент от программного кода.
*   **Q3 2026: AI Tutor**. Интеграция LLM для динамической генерации подсказок на основе ошибок ученика в коде.

## 🚀 Быстрый старт

Проект готов к промышленному деплою на Vercel с настроенным CI/CD пайплайном.

1.  **Установка**: `npm install`
2.  **Разработка**: `npm run dev` (Vite Hot Reload)
3.  **Сборка**: `npm run build` (Tree-shaking включен, ассеты оптимизированы)
