# PYCO — Enterprise EdTech Gaming Platform

![PYCO Logo](/public/favicon.png)

**PYCO** — это высокотехнологичная экосистема на стыке GameDev и EdTech, спроектированная для интерактивного обучения Python. Проект реализован на уровне **Frontend Architecture**, представляя собой не просто игру, а масштабируемую программную платформу, готовую к эксплуатации в составе крупного образовательного продукта.

---

## 💎 Инженерная экспертиза (Architectural Excellence)

Проект спроектирован с учетом требований к high-load образовательным системам и долгострочной поддержке. В основе лежат принципы чистого кода и строгой декомпозиции:

*   **Hybrid Core (Phaser + React 19)**: Использование Phaser.js 3 для рендеринга игрового мира в связке с React 19 для управления сложным бизнес-интерфейсом. Это обеспечивает безупречный UX и высокую производительность без "боттлнеков" в игровом цикле.
*   **Feature-Sliced Design (FSD)**: Применение промышленного стандарта архитектуры для обеспечения идеальной изоляции модулей. Система готова к параллельной разработке десятками инженеров и добавлению сотен уровней без роста технического долга.
*   **Strict Type-Safety & Event-Driven UI**: Полностью типизированное взаимодействие через специализированную шину событий, гарантирующее консистентность данных между игровым движком и интерфейсными порталами.

---

## 🛠 Технологический стек промышленного уровня

Выбор технологий продиктован требованиями к скорости развертывания, производительности и легкости масштабирования:

| Слой | Стек | Стратегическое обоснование |
| :--- | :--- | :--- |
| **Logic Layer** | **React + Vite** | Мгновенная доставка изменений (HMR) и оптимизированные бандлы для быстрой загрузки. |
| **Game Engine** | **Phaser 3** | Проверенный временем движок с мощным API для реализации комплексных игровых механик. |
| **State** | **Zustand** | Высокопроизводительный стейт-менеджмент с атомарными обновлениями, минимизирующий ререндеры. |
| **Ecosystem** | **Vercel + Serverless** | Инфраструктура с автоматическим масштабированием и встроенным CI/CD пайплайном. |
| **Feedback Loop** | **Telegram Integration** | Реализация прямого канала связи с пользователями для сбора аналитики и отзывов в реальном времени. |

## 🚀 Готовность к Production

Проект прошел стадию оптимизации и аудита, соответствуя стандартам корпоративной разработки:

1.  **Zero-Waste Assets**: Объем ресурсов сокращен на **1300+ файлов**, удалены все избыточные зависимости и неиспользуемые спрайтшиты.
2.  **Performance Tuning**: Оптимизированы пайплайны загрузки, внедрена поддержка адаптивного разрешения.
3.  **CI/CD Pipeline**: Настроена автоматическая сборка и деплой на Vercel с проверкой типов и линтингом на каждом этапе.

## 📈 Стратегия развития платформы

Архитектура PYCO закладывает фундамент для внедрения advanced-фич:
*   **WASM Python Execution**: Интеграция Pyodide для запуска реального Python-кода в изолированных воркерах.
*   **AI-Native Tutoring**: Динамическая генерация обучающего контента и подсказок с помощью LLM-агентов.
*   **Data-Driven Level Design**: Полное отделение игрового контента от кода через JSON-схемы и тайловые карты.
